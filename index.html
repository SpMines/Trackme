“Hey Samm” & desktop app

Desktop app: install SAMM on your PC — own window, taskbar icon, opens like an app. Best in Microsoft Edge (free natural voices). To open it when Windows starts: Edge → edge://apps → right-click SAMM → Start app when you sign in.

Siri (iPhone Shortcut)

Say “Hey Siri, SAMM” → speak → SAMM opens in Safari and answers. Your secret code stops anyone else’s link from running commands — links without it only fill the box and wait for your tap.

  1. iPhone → Shortcuts app → + → name it SAMM.
  2. Add action Dictate Text (language: English (India) or Hindi).
  3. Add action URL → paste the URL above, delete TEXT at the end and insert the Dictated Text variable there.
  4. Add action Open URLs. Done → say “Hey Siri, SAMM”.
  5. Safari keeps its own settings: open SAMM once in Safari and add your Groq key / key proxy there too.

Gmail (your own Apps Script)

SAMM reads your unread mail only when you ask (“koi important mail aaya?”), and saves drafts or sends only when you tap (max 20 sends/day). Deploy samm-gmail.gs from your Google account, then paste its URL and token. Stays only in this browser.
